NTU-A*STAR joint project
WP 2.2 Spatially-Grounded Perception and Planning for Embodied AI Agents

Demonstrator: distributed planetary gearbox assembly in MuJoCo.
Robot model: AgileX Ranger Mini 3.0 and two RealMan RM75 arms.
Workflow: explore, build the object graph, select the object chain, collect parts,
assemble the gearbox, use a wall-mounted driver, fasten three captive screws,
and return the driver.

Presentation: main video with floating RGB-D, Graph as Policy, object relations,
and a third-person 3D object graph using the same camera as the main video.
Duration: 322.2 seconds. Resolution: 1920 x 1080. Frame rate: 15 fps.
Playback: 3x recorded simulation time, with a final hold. No audio track.
